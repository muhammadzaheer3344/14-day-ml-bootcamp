# 14-Day Real-World ML Bootcamp

A 14-day hands-on machine learning bootcamp — daily topics, real-world datasets, and end-to-end projects covering the full ML workflow from EDA to deployment.

## 📌 About

Each day focuses on a specific ML concept, applied to a real Kaggle dataset with a complete project. The goal is to build practical, portfolio-ready skills across data cleaning, feature engineering, regression, classification, ensemble methods, clustering, model selection, imbalanced data handling, and deployment.

## 🗂️ Repository Structure

```
├── Day01_EDA_Data_Cleaning/
└── Day02_Feature_Engineering/
.
.
.
```

Each folder contains its own `README.md`, notebook(s), and processed data/outputs for that day. More folders will be added as the bootcamp progresses.
